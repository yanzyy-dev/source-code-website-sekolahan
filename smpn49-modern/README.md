SMPN 49 Makassar — Retro Next.js

Website profil SMPN 49 Makassar dengan konsep retro editorial / school archive.

Website ini menggabungkan dokumentasi sekolah, informasi publik, dan antarmuka modern dalam satu pengalaman digital yang terstruktur.

About

Project ini dibuat sebagai website profil digital untuk:

UPT SPF SMP Negeri 49 Makassar

Konsep visual mengambil pendekatan:

- Retro editorial
- School archive
- Documentary photography
- Modern web interaction
- Responsive layout

Fokus utamanya adalah membuat website sekolah yang terasa memiliki identitas visual sendiri, bukan sekadar landing page dengan layout standar.

---

School Data

Data yang tersedia pada sumber tersebut mencakup identitas satuan pendidikan, NPSN, alamat, status sekolah, dokumen/perizinan, sarana prasarana, dan informasi kontak.
